# Changelog

## 2.1.0

First public Windows x64 release of Drift.

- Play silent video wallpapers behind desktop icons.
- Convert authenticated MLW files to MP4 without overwriting existing videos.
- Rotate a selected playlist at configurable intervals or use daily schedules.
- Save the video library and preferences, with optional restoration at sign-in.
- Keep wallpapers running in the tray and pause automation with Stop.
- Display the Drift name, logo, and Windows icon throughout the app.
- Fix frozen wallpapers caused by hidden maximized windows triggering auto-pause.
- Show a paused status when the foreground application pauses playback.
- Fix the Import/Browse file-dialog crash.

The portable download requires mpv separately. Only Windows x64 is included.
